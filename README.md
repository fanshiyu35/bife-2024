# BIFE 2024

Official website for the International Conference on Business Intelligence and Financial Engineering (BIFE 2024).

Live site: https://bife-conference.org

## Structure

- `index.html` — landing page
- `about.html`, `cfp.html`, `committee.html`, `contact.html` — conference info pages
- `keynotes.html`, `papers.html`, `program.html`, `registration.html`, `venue.html` — program pages
- `papers/` — individual paper detail pages (P001–P006)
- `assets/` — CSS, images, JS
- `style.css` — top-level stylesheet
- `CNAME` — custom domain configuration for GitHub Pages
